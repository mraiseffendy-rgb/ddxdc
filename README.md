## 🚀 &nbsp;Cara Running · How to Run · Запуск

</div>

```bash
# 1) Install / Установка
pkg install nodejs git nano -y && mkdir -p ~/ranz && cd ~/ranz && nano ranz.js
```

```bash
# 2) Token GitHub / GitHub-токен
echo 'export GITHUB_TOKEN="ghp_xxxxxxxxxxxx"' >> ~/.bashrc && source ~/.bashrc
```

```bash
# 3) Jalankan / Run / Запуск
node ranz.js
```

> 💡 **ID:** arahkan kursor ke blok kode → klik **Copy**.
> **EN:** hover a code block → click **Copy**.
> **RU:** наведите курсор на блок кода → нажмите **Copy**.
